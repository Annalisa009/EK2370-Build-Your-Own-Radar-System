# EK2370 - Build Your Own Radar System

This repository contains MATLAB scripts and images for the EK2370 radar project.

## Files
- `Range.m` - Range measurement
- `Range_doppler.m` - Range-Doppler processing
- `RMA_real.m` - RMA with real data
- `RMA_simulated.m` - RMA with simulated data
- `SAR_t_domain_corr.m` - SAR time domain correlation
- `velocity.m` - Velocity estimation
- `realtime_velocity.m` - Real-time velocity
- `cw_range.m` - CW range
- `range_real_time_fmcw.m` - Real-time FMCW range

## Images
- `COTS_measurements/`
- `Hardware images/`
- `SAR images/`
- `SDR images/`

## Report
- `EK2370_Build_your_own_radar_system_Group_5_report.pdf` - final report for the course with analysis and comments
